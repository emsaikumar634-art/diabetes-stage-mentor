📌 Project Overview

Diabetes Type 2 Stage Mentor is a patient-focused digital health companion that helps users record glucose readings, monitor health patterns, track daily activities, review weekly progress, and access diabetes-related educational information.

The application is designed to provide supportive insights without prescribing medication or replacing professional medical advice.

✨ Key Features

- 📊 Glucose tracking and history
- 📈 Glucose trends and personal baseline
- 🩸 Daily glucose check-ins
- 🚶 Daily activity tracking
- 🍎 Healthy food education
- 💊 Medication awareness and adherence support
- 📚 Diabetes education hub
- 🤖 AI-assisted health insights
- 📋 Weekly health review
- ⚠️ Risk classification such as Stable, Needs Attention, and Significant Change
- 🔐 Privacy and security considerations
- 📱 Responsive design for desktop and mobile screens

🚀 Run Locally

1. Install dependencies

npm install

2. Start the development server

npm run dev

3. Open the application

Open the local URL shown in the terminal, usually:

http://localhost:5173/

🏗️ Production Build

npm run build

The production files are generated in the "dist" folder.

🔒 AI Safety

The AI insights in this prototype are intended for educational and supportive purposes only.

The application does not prescribe medicines, change medication doses, or replace a healthcare professional.

Users are encouraged to consult an appropriate healthcare professional when significant changes or concerns are identified.
